OpenDRT

OpenDRT display transform as native Blender compositor node groups, served as a Blender remote asset library.

Add it in Blender: Preferences → Asset Libraries → add an online asset library with URL https://zicklag.github.io/blender-opendrt/. Then add the “OpenDRT 1.1 …” node groups from the asset browser, the compositor asset shelf, or the Add search menu.
